# Pool Assist

Android prototype for a visual billiards aiming assistant.

## Current features
- Pick a screenshot from the device.
- Display the screenshot.
- Analyze mode with a visual table boundary and aiming/bounce guides.
- Clean Kotlin + Jetpack Compose project structure.

## Scope
This project is a visual aiming assistant. It does not automate gameplay, send game commands, or connect to a game's online server to play on the user's behalf.

## Build
Open the project in Android Studio and build the `app` module.
